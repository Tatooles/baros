# Present Active Workout as a minimizable session

Baros keeps three permanent tabs—History, Home, and Profile—with Home selected by default. An Active Workout appears as a native full-height sheet; the system grabber minimizes it without ending the workout, and a native expanded bottom accessory provides status and re-entry while preserving the selected tab underneath. This keeps navigation stable and truthful; finish, discard, and owner-change removal return Home, iOS 26.0 remains supported through one localized compatibility boundary, and inline accessory adaptation and a workout utility bar remain out of scope.
