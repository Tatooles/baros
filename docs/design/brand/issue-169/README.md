# Baros icon front-runner checkpoint

This directory preserves the current design front-runner for GitHub issue
[#169](https://github.com/Tatooles/baros/issues/169).

`baros-icon-front-runner-3.png` is a standalone concept rendering derived from
option 3 of the tight-gap plate study. It establishes the intended direction:

- an uppercase Latin `B` that reads clearly at small sizes;
- a slim vertical barbell integrated as the letter's left stem;
- two thin, moderately extended cobalt plates at each end;
- tight spacing between the stem and bowls so the mark remains cohesive; and
- a charcoal, cobalt, and warm-silver visual system.

This PNG is a design reference, not a production app-icon resource. Before it
is installed in the app, the selected mark must be rebuilt as maintainable
vector artwork, optically refined, assigned exact production colors, and
validated across the required Apple icon appearances and sizes.
